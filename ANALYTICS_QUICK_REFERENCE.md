# Google Analytics Quick Reference Card
## Nutri Kitchen - Print and Keep This Handy!

## 🚀 SETUP (ONE-TIME)

### Step 1: Create Account
→ Go to: **analytics.google.com**
→ Sign in with Gmail
→ Click "Start measuring"

### Step 2: Get Measurement ID
→ Property name: **Nutri Kitchen Website**
→ Platform: **Web**
→ URL: **nutrikitchen.com**
→ Copy ID: **G-XXXXXXXXXX**

### Step 3: Update Website
→ Open: **index.html** and **products.html**
→ Find: **G-XXXXXXXXXX** (appears twice in each file)
→ Replace with your actual ID
→ Save and upload

### Step 4: Verify
→ Visit your website
→ Check: **Realtime** in Google Analytics
→ Should see 1 user (you!)

---

## 📊 DAILY CHECK (2 minutes)

**Every Morning:**
1. Open: **analytics.google.com**
2. Click: **Reports** → **Snapshot**
3. Look at: **Users** (yesterday)

**Quick Questions:**
- More users than yesterday? ✅
- Which page is popular today? 
  → **Engagement** → **Pages**

---

## 📈 WEEKLY REVIEW (15 minutes)

**Every Monday Morning:**

### 1. Total Visitors
→ **Reports** → **Snapshot**
→ Date range: **Last 7 days**
→ Write down: **_______ users**

### 2. Traffic Sources
→ **Reports** → **Acquisition** → **Traffic**
→ Which is biggest?
  - Organic Search (Google)
  - Social (Instagram, Facebook)
  - Direct (typing URL)

### 3. Top Products
→ **Reports** → **Engagement** → **Pages**
→ Top 3 pages: **________________**

### 4. Geographic Data
→ **Reports** → **User** → **Demographics**
→ Top cities: **________________**

**Action**: Focus ads on top cities!

## 💡 COMMON QUESTIONS & WHERE TO FIND ANSWERS

| Question | Where to Check |
|----------|---------------|
| How many people on site NOW? | **Realtime** |
| How many visitors today? | **Reports** → **Snapshot** |
| Which product is most popular? | **Engagement** → **Pages** |
| Where do visitors come from? | **Acquisition** → **Traffic** |
| What cities visit most? | **User** → **Demographics** |
| Mobile or desktop more? | **User** → **Tech** |
| Did my post work? | **Realtime** (right after) |

## 🔧 TROUBLESHOOTING

**No data showing?**
✓ Wait 24-48 hours
✓ Check Measurement ID is correct
✓ Visit site yourself (should show in Realtime)

**Data seems wrong?**
✓ Exclude your own IP address
✓ Check date range is correct
